预测下一个，为什么就能生成全部？

本节目标：从概率链式法则推到逐 token 生成，并分清训练时的真实前缀与推理时的模型前缀。

1. 链式法则给出建模路线

把一句话切成 token 序列 x₁,x₂,…,xₙ。token 可能是一个字、一个词或词片；数学推导与具体切法无关。联合概率总可以写成：

pθ(x₁,…,xₙ)=∏ₜ₌₁ⁿ pθ(xₜ|x₁,…,xₜ₋₁)

例如“小明 买 书”的概率等于 p(小明)×p(买|小明)×p(书|小明,买)。这就是自回归：当前位置的预测依赖已经出现的前缀。[Transformer 原论文]

若三个条件概率依次是 0.2、0.5、0.4，则整句概率为 0.2×0.5×0.4=0.04。提高真实下一个 token 的条件概率，就能提高训练句子的整体概率。

2. 训练时：答案已知，用真实前缀

给模型真实句子“小明 买 书”。训练样本可以同时构造成：

输入前缀：〈开始〉 → 预测“小明”

输入前缀：〈开始〉 小明 → 预测“买”

输入前缀：〈开始〉 小明 买 → 预测“书”

每个位置都用真实的先前 token作为上下文，这常称为 teacher forcing（教师强制）。训练目标是最大化各位置真实 token 的对数概率，通常写成负对数似然损失：

L(θ)=−Σₜ log pθ(xₜ|x₁,…,xₜ₋₁)

如果模型使用因果掩码的 Transformer，所有真实前缀已在同一条序列中，训练可并行计算多个位置的预测；这不意味着生成时能一次知道未来 token。[Transformer 原论文]

3. 推理时：答案未知，用模型刚生成的前缀

生成时模型先从 pθ(x₁) 选择或采样 x₁，再从 pθ(x₂|x₁) 取得 x₂，以此类推。若第二步生成了错误的“卖”，第三步只能根据“小明 卖”继续，而不能悄悄换回训练集中的“小明 买”。

训练与生成的差别：训练：真实前缀 → 预测真实下一个；推理：模型前缀 → 采样下一个。教师强制让单步学习清晰、训练高效，但不保证推理时没有错误累积；两阶段前缀来源不同会带来暴露偏差。[Bengio 等，2015]

4. 为什么图像也能自回归？

像素或图像离散编码也能排成序列，按某个顺序逐个预测下一个。链式法则对不同顺序都成立；但有限容量模型、网络结构与训练效率会使具体顺序影响学习效果。PixelRNN 就研究了逐像素生成。[PixelRNN 原论文]
