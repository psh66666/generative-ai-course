Transformer：一个 token 怎样读取上下文？

本章的主问题是：预测下一个词时，模型怎样根据当前内容，从任意早期位置读取有用信息？Transformer 用注意力计算“读哪里、读多少”，再用前馈网络处理汇总后的表示。它是一种网络结构；是否按自回归方式生成，由训练目标和掩码共同决定。[Transformer 原论文]

1. 先把序列变成可计算的表示

文本先分成 token，查嵌入表得到向量 X。注意力本身只比较向量内容；若没有位置相关信号，模型难以区分“猫追狗”和“狗追猫”的顺序，所以还需位置编码或其他位置机制。每一层接收整段序列的向量，并为每个位置产生新的表示。

token 与位置信息→Q/K/V 投影→注意力汇总→前馈网络→下一层

2. Q、K、V 分别负责什么？

同一层输入矩阵 X 经三组可学习权重变换：Q=XWQ、K=XWK、V=XWV。某位置的 Q 与每个允许读取位置的 K 做点积；分数越高，通常越倾向读取该位置的 V。虽然自注意力中的三者都来自 X，它们的投影参数和计算角色不同。

Attention(Q,K,V)=softmax(QKᵀ/√dk+M) V

M 是掩码；不允许读取的位置填入极小值，使 softmax 后权重约为 0。除以 √dk 是因为点积维度大时数值方差通常随维度增加，缩放有助于避免 softmax 过早变得极端。这是数值动机，不是说 Q 与 K 的语义会因此相同。[原论文，第 3.2 节]

3. 两个位置的数字例子

先暂时忽略缩放，假设当前位置 Q=(1,0)，两个位置的 K 分别是 (1,0)、(0,1)。匹配分数就是 1 和 0；softmax 后的权重约为 0.731 和 0.269。如果对应 V 是标量 2 和 6，汇总值约为 0.731×2+0.269×6=3.08。输出是按匹配权重汇总 V，不是用 Q、K 直接生成词表概率。

真实模型里的 V 是向量；这一结果还要经过输出投影、残差、归一化、前馈网络以及后续层，最后由词表投影产生 logits，再经 softmax 得到下一 token 概率。这个例子只隔离了注意力最核心的一步。

4. 自注意力、多头与整层结构

自注意力指 Q/K/V 来自同一序列。多头注意力使用多组不同投影并行读取，再把结果拼接和投影；各头可能学习不同关系，但不能预先保证某头固定代表“语法”或“事实”。一个 Transformer 层还包含逐位置前馈网络，以及残差连接与归一化，帮助层叠和训练。注意力负责跨位置交换信息；前馈网络在每个位置上进一步变换汇总后的向量。

5. 因果掩码怎样把结构接到生成任务？

decoder-only 语言模型在输入位置 i 看到 x₁,…,xᵢ，用该位置的输出预测下一项 xᵢ₊₁。训练时整段真实文本已在内存中，因果掩码仍必须挡住输入位置 i 之后的 token，否则会偷看待预测内容。它允许一次并行算出多个位置的训练损失，但每个目标 token 的条件仍只是自己的过去。

pθ(x₁,…,xₙ)=∏ᵢ pθ(xᵢ|x<ᵢ)
输入位置 i 的掩码 Mij=−∞ 当 j>i；否则允许注意
输入位置 i 的输出预测 xᵢ₊₁

原始 Transformer 论文使用编码器与解码器：编码器自注意力可读双向上下文；解码器自注意力用因果掩码；解码器还有读取编码器输出的交叉注意力。今天常见的 decoder-only LLM 则没有那条单独的编码器路径。讨论“Transformer”时先说清是哪种结构。[原论文，图 1 与第 3 节]

6. 训练与推理为什么运行方式不同？

训练

给真实前缀，因果掩码保证每个位置只看以前的 token；在一批位置同时计算下一 token 交叉熵。此时没有“先生成错一个再继续”的路径。

推理

拿当前前缀算下一 token 概率，按选定采样规则选一个，再把它放回前缀，重复。过去位置已经算过的 K/V 可缓存；新位置仍需计算自己的 Q/K/V、与过去 K 的匹配以及后续层。KV 缓存省的是旧投影的重复计算，不是把注意力整体省掉。

如果推理时前一个 token 选错，后续条件分布就在错误前缀下计算。位置可以通过注意力跨较远距离交换信息，但能否真正利用远处内容，仍取决于训练、容量、位置机制和上下文长度。

7. 与扩散模型中的注意力怎样联系？

文本生成图片的 LDM 在去噪网络中用交叉注意力：图像潜特征提供 Q，文本编码特征提供 K/V。语言模型的自注意力则在同一 token 序列内读取上下文。两者复用同一个注意力公式，却服务于不同的生成过程；注意力模块本身不规定最终是逐 token 生成还是逐步去噪。[LDM 原论文，第 3.3 节]
