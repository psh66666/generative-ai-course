耦合层为什么既可逆又好算？

上一节知道：流模型需要一条可逆的 x↔z 路，也需要雅可比行列式修正密度。本节解决设计问题：普通复杂变换很难同时满足这两点，Real NVP 用“固定一半，变换另一半”的耦合层做到。

1. 先看要解决的计算困难

如果 x 是一张高维图片，任意神经网络从 x 变到 z，未必能轻易反算 x；即使可逆，完整雅可比矩阵很大，行列式也可能难算。流模型需要足够灵活的变换，又要容易求逆和算密度。

2. 两个数的玩具耦合层

先把输入分成两部分 (x₁,x₂)。让第一部分直接通过；第二部分根据第一部分给出的缩放 a(x₁) 与平移 b(x₁) 变化：

z₁=x₁
z₂=a(x₁)·x₂+b(x₁)，要求 a(x₁)≠0

例如 x₁=2、x₂=3，且 a(2)=2、b(2)=1，则 z₁=2，z₂=2×3+1=7。你已经得到 z=(2,7)。

逆向求 x 很简单：从 z₁=2 立即知道 x₁=2，再把 z₂ 的平移减掉、缩放除掉：x₂=[z₂−b(z₁)]/a(z₁)=(7−1)/2=3。a 和 b 即使用复杂神经网络计算，也不需要把那台神经网络本身求逆。

3. 为什么行列式也容易算？

雅可比矩阵记录 z₁、z₂ 分别怎样随 x₁、x₂ 改变。由于 z₁=x₁，z₁ 完全不受 x₂ 影响，右上角一定是 0：

J = [ [1, 0], [∂z₂/∂x₁, a(x₁)] ]

二阶矩阵行列式按“左上×右下−右上×左下”算，所以 det J=1×a(x₁)−0×(复杂项)=a(x₁)。即使 a、b 是复杂网络，左下角可能难算，行列式仍只需读出缩放 a。上面数字例子的体积缩放率就是 2。

4. Real NVP 怎样确保缩放不为零？

让网络输出 s(x₁) 和 t(x₁)，把缩放设成 exp(s(x₁))，它始终大于零：

z₁=x₁
z₂=x₂·exp(s(x₁))+t(x₁)
log|det J|=s(x₁)

多维输入时，把 x 分成两组；未变的一组控制另一组的逐元素缩放和平移。整层的 log 行列式就是各缩放输出 s 的和。[Real NVP 原论文，第 3.2–3.5 节]

5. 为什么下一层要交换两组？

假设每层都固定第一组。无论叠多少层，第一组最终仍是原来的数：z₁=x₁。模型能改变 x₂，却永远不能改变 x₁ 的分布。例如先验的第一维是以 0 为中心的标准正态，而真实数据的第一维主要聚集在 −3 和 3 附近；始终固定第一维的模型无法把前者变成后者。

两层的数字演示：第一层固定 x₁，让 x₂ 变成 u₂=2x₂+1，同时 u₁=x₁；第二层反过来固定 u₂，让 u₁ 变成 z₁=u₁+u₂，同时 z₂=u₂。输入 x=(2,3) 时，第一层得到 u=(2,7)，第二层得到 z=(9,7)。现在第一维也能变化，并且它的变化受到第二维影响。

所以每一层保留一部分，是为了容易求逆、容易算行列式；层与层之间交替交换，是为了避免某一部分永远原样通过。每一层单独仍保持简单的三角形雅可比结构。

6. 与训练、生成路径接起来

这里把耦合层写成 x→z，便于对真实 x 计算 z 和 log|det J|，再用上一节的变量替换公式算 log pX(x) 来训练。生成新样本时，先抽 z，再把这些耦合层按相反顺序逐层求逆，得到 x。网络内部没有另一台单独训练的“编码器”。
