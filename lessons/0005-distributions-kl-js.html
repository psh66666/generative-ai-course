两个分布相差多少？

本节目标：把“生成结果像真实数据”说成可计算的问题，理解 KL 散度为什么有方向，以及 JS 散度怎样用一个中间分布实现对称比较。

1. 比较的不是两张图片，而是出现频率

先把结果简化成“猫”与“狗”。真实数据分布 P 中，猫占 90%，狗占 10%；模型分布 Q 中，猫狗各占 50%。单个样本可能都看起来合理，但整体比例不同。生成建模常要让模型分布在某种意义上接近数据分布。

P=(0.9, 0.1)　真实数据：猫多狗少

Q=(0.5, 0.5)　模型输出：猫狗一样多

2. KL：以 P 为基准看 Q 有多不合适

KL(P‖Q) = Σₓ P(x) log[P(x)/Q(x)]

在 P 常出现的结果上，若 Q 给的概率很低，惩罚就很大。KL 的整体值非负，P 与 Q 一致时为 0；但它不是普通距离，因为换顺序通常改变结果：KL(P‖Q) 通常不等于 KL(Q‖P)。特别地，若 P 某处概率大于 0，而 Q 在该处给 0，则 KL(P‖Q) 为无穷大。[Murphy，Probabilistic Machine Learning]

直观地说，KL(P‖Q) 对“真实会出现、模型却认为绝不可能”的情况尤其敏感。公式中的每一项可以是正也可以是负，总和才保证非负。

3. JS：先取中间分布，再从两边比较

M = (P + Q)/2
JS(P,Q) = ½KL(P‖M) + ½KL(Q‖M)

JS 把 P 与 Q 的平均分布 M 当共同参照，因此 JS(P,Q)=JS(Q,P)。纪要说它是“KL 的对称化版本”，可作直觉，但它不是简单计算 [KL(P‖Q)+KL(Q‖P)]/2；关键在于先引入 M。以自然对数计算时，JS 的取值在 0 到 ln2 之间。[Lin，1991]

一个极端例子：P=(1,0)，Q=(0,1)。两者完全没有重叠，KL(P‖Q) 和 KL(Q‖P) 都无穷大；M=(0.5,0.5)，所以 JS(P,Q)=ln2，仍是有限值。

后面学 GAN 时还会遇到 JS；学极大似然时会重新看 KL 的方向。此刻先掌握“比较谁、方向是否影响结果、零概率会怎样”。
