SFT：从“会续写”到“按指令回答”

预训练模型学的是一般文本续写分布。用户希望它把一段文字识别为指令，并按要求给出回答。监督微调（SFT）给模型大量“提示 → 期望回复”的示范，用与预训练相似的 token 预测损失，改变模型在指令上下文下的行为。[InstructGPT 原论文，第 3 节]

1. 数据长什么样？

一条样本可以包含系统约束、用户问题、已有对话和人工或其他流程提供的目标回答。把它序列化为模型能读的 token 后，训练通常让提示作为条件，只把要模型生成的回复部分作为监督目标。对多轮对话，还要明确每段消息的角色与边界，否则模型难以区分“用户说的话”和“自己该输出的话”。

玩具样本：用户：“请用一句话解释什么是 VAE 先验。”目标助手：“它是无输入生成时抽取潜变量 z 的预先约定分布。”模型在训练时看到提示和真实回复前缀，逐 token 提高目标回复的概率。

好的示范不只要语句通顺，还应与指令一致、可核对、覆盖不同任务。数据里若把错误答案当目标，SFT 会提高错误答案的条件概率；优化器不会自己判断示范是否真实。

2. 损失与预训练有什么相同和不同？

数学形式仍是条件负对数似然。设提示为 x，目标回复 token 为 y₁,…,yₘ：

LSFT(θ)=−Σᵢ₌₁ᵐ log πθ(yᵢ|x,y₁,…,yᵢ₋₁)

训练时的 y₁,…,yᵢ₋₁ 是真实回复前缀，所以能并行计算所有位置。具体实现可给提示位置的损失乘 0、给目标回复位置乘 1；模型仍会在注意力里读取提示，只是不要求把提示本身当作助手答案来预测。不同训练方案的掩码约定可能不同，研究论文要查看其确切数据格式与 loss mask。

预训练与 SFT 的数学工具相近，但数据条件与期望行为不同：预训练样本来自广泛文本，SFT 样本明确展示某类输入下应怎样回答。SFT 可以全量更新，也可以通过第 12 章的 LoRA 更新少量参数；目标和参数更新方式是两条轴。[InstructGPT 原论文]

3. 用一个数理解 SFT 在推动什么

给定“2+2 等于多少？”这个提示，假设模型给目标回复“4”的概率为 0.1，则该位置损失 −log0.1≈2.30。训练若把它提高到 0.8，损失降为约 0.22。softmax 归一化也会影响其他候选，但这条样本直接提供的是一个示范答案，不是一份“A 比 B 更好”的成对偏好标注。

如果一个提示有多种合理回答，单个示范并不列举所有可能；SFT 学的是示范数据的条件分布。它可以改善指令遵循，却不能仅靠训练损失下降证明模型在开放世界中事实正确、稳健或适合每类用户意图。

4. 训练与真实对话之间有什么落差？

训练：提示 + 真实回复前缀→预测目标下一 token
推理：提示 + 自己已输出的前缀→采样下一 token

这与自回归模型的教师强制相同：推理早期若回答偏离示范，后续将基于自己产生的新上下文继续。多轮对话还会引入更长的历史以及用户的新要求。因此评估不能只看训练集上的 token 损失，还需要在未见过的提示上检查完整回答，例如指令遵循、事实性与任务完成情况。

5. 为什么还要偏好训练？

SFT 告诉模型“这一条示范可接受”，但某些质量维度更容易通过比较表达：同一问题的两个回复，哪一个更清楚、更符合要求？第 14 章的奖励模型、RLHF 和 DPO 会利用这样的偏好对。它们不是 SFT 必须经历的唯一后续步骤，而是进一步改变回复排序与生成行为的训练方案。
